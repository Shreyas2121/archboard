## State boundaries and limitations

The Y.Doc is the sole editable graph state; document-model commands own durable mutation ([P2-02](./evidence/phase2/P2-02.md)). React Flow converts validated projection objects and reports interaction intent; Zustand stores selection IDs/kinds, panels, dialogs, theme-related UI choices, and other ephemeral state, not graph copies ([P2-05](./evidence/phase2/P2-05.md), [P2-06](./evidence/phase2/P2-06.md)). The Web Lock determines write authority; BroadcastChannel messages are hints only ([P2-04](./evidence/phase2/P2-04.md)). Reset clears the exact demo namespace while holding the writer lock, and recovery exports a validated in-memory projection without claiming import support ([P2-11](./evidence/phase2/P2-11.md)).

`Saved on this device` means the local IndexedDB write completed. It does **not** mean server persistence, account backup, or collaboration synchronization. The demo has no collaboration socket or graph API request in its recorded production run. Reload-safe local storage while the application shell is available is **not** service-worker-backed offline route navigation. Authentication, live collaboration, service-worker offline navigation, multi-browser certification, presentation keyboard coverage, and release readiness remain outside this milestone.

The named typical fixture contains 200 nodes, 400 edges, 20 boundaries, and 20 steps. On the recorded Windows/Chrome reference machine, five cached opens had a 1,084.5 ms median and 1,275.0 ms worst case against 2,000 ms; drag p95 was 16.8 ms with one durable update; pan p95 was **83.3 ms against a 32 ms limit** with zero durable updates. An earlier valid pan run missed at 50.2 ms. The measurement script exits nonzero, so this cannot be interpreted as a passing quality gate. [P2-12](./evidence/phase2/P2-12.md) contains method, raw samples, machine, build mode, and fixture bytes.

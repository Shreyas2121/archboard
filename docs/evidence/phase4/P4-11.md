## Behavior

Authenticated board sockets accept strict, bounded `presence` frames. The server derives user ID and display name from the Better Auth session, assigns a stable color and connection ID, broadcasts only to ready peers on the same board, drops traffic above 15 messages per rolling second, and sends an empty removal state after 30 seconds or socket disconnect. An arriving peer receives still-current presence. Presence never enters the room's Y.Doc or persistence path.

The sync client coalesces pointer and drag messages to at most 15 per second and stores peer presence only in connection-local memory. It discards peers on expiry, reconnect, or disconnect. The editor publishes selection, world-coordinate cursor, and transient drag positions; selections above 100 publish a count. Peers see cursors, selections, names, and preview outlines over the committed canvas. Existing drag-stop geometry handling makes one durable edit at the end of a drag. Closing a sender mid-drag leaves the last committed geometry visible.

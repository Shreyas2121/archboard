## Implemented boundary

Every socket update rechecks its Better Auth session under the room queue. Graph authority is checked before receipt lookup and worker validation, then checked again while holding the board row lock. Exact decoded bytes are SHA-256 hashed. A matching `(boardId, updateId, actor, hash)` returns its original decimal sequence; a mismatched actor or payload receives `UPDATE_ID_REUSED`. The transaction increments `latest_seq`, updates `content_updated_at`, and inserts one update and one receipt atomically. Only after commit does the room install the validated candidate, ACK the sender, and broadcast the exact bytes to other room subscribers. Failed validation or commit leaves the room unchanged and sends no ACK or peer update. The shared per-connection content rate budget is enforced before admission.

## Behavior proved

Implemented a named Share board control in the authenticated editor toolbar using
the existing Dialog, Select, Button and IconButton primitives. It shows the owner,
members, text role labels, loading, refresh, error and pending states. Names are
rendered as text. Demo editor sessions have no sharing control. Sharing blocks editor
shortcuts while open and provides focus-return callbacks and live status/error regions.
Rendered accessibility and keyboard acceptance remain UNRUN.

Only a verified current owner can change editor/viewer roles or remove another
member. The owner row has immutable ownership and no management controls. Other
authorized readers see the list and may leave their own membership. Offline,
archived, unauthenticated, wrong-account, denied and unverified authority disable
writes with a reason. Cached lists show a fetch timestamp and possible-staleness label.

Every write refetches metadata and members before rechecking authority and sending
the request. Committed owner actions invalidate/refetch both resources using P6-04's
adapter, including when the actor receives no socket hint. Submitted Select input
never becomes permission authority. Failed or uncertain writes reconcile through
reads without automatically retrying a mutation. A missing target member after PATCH
triggers reconciliation; authoritative board/member read denial ends board access.
The distinction is implemented in the hook; its rendered race acceptance is deferred.

Self-leave freezes graph editing and sending, waits for existing sync/local writes,
and inspects pending work for the exact deployment/account/board across schema
versions. Pending work uses the existing preservation dialog with download, Cancel,
and explicit leave-and-retain actions. It exposes no clearing action. A second pending
ID/count check and authority check precede the removal port. Cancel stops a late
preparation continuation. Export failure leaves the recovery prompt and data intact.
Successful self-leave ends protected reads and sending while retaining local recovery
data. Removal explanations state that downloaded device copies cannot be erased remotely.

Fourteen focused Node cases prove the pure authority/coordinator rules and actual
member/API adapter behavior. Six P6-04 Node regressions prove scoped invalidation
and graph transport isolation. They do not run React, IndexedDB, a browser or a live
server. Backend permission/persistence units pass independently of a database.

## Contracts used

- Existing `GET /api/boards/:boardId` metadata and
  `GET /api/boards/:boardId/members` responses supply current authority and rows.
- Existing `PATCH /api/boards/:boardId/members/:userId` accepts only validated
  editor/viewer roles; DELETE on the same member path returns 204. Mapped auth IDs
  are encoded as URL segments without assuming UUIDs. Requests use credentials
  and AbortSignals; response envelopes retain shared Zod validation.
- The API adapter accepts 204 only when the supplied response schema accepts
  undefined. A 204 cannot satisfy an object response contract. 401/403/404 remain
  errors; the global unauthorized listener still handles expired sessions.
- Query prefixes include deployment origin, account, board and resource. Existing
  P6-04 access/reconnect hints refresh reads. Hints and cached roles never authorize
  a mutation. Archived state from either the session or REST blocks writes.
- Queued graph work stays under its existing namespace. Relational membership
  operations do not create graph commands, clear outboxes or modify graph schemas.

## Changed scope

leave coordinator, query/mutation hook, member list and dialog composition. Existing

logic. The shared preservation dialog gains optional leave/retain composition while
existing sign-out/account-switch callers keep their clearing behavior.

The platform API adapter handles the existing no-content contract. Root script
`scripts/p6-05-sharing.node.test.mjs` contains focused tests without introducing
frontend-owned test files or dependencies. This evidence is the documentation addition.

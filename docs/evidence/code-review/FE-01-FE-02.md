## FE-01: committed local snapshots and saved status

The persistence adapter tracks reserved and committed local sequences separately.
Compaction rechecks pending work and storage availability after its database reads,
then captures snapshot bytes and the committed frontier synchronously. An edit
arriving during snapshot persistence remains in the queue and cannot enter that
snapshot. Saved status is published only when no writes remain pending. Local
log/outbox transactions and snapshot-before-log-deletion ordering are preserved.

The Node regression uses a controlled database model to pause each compaction
await: snapshot read, log read, snapshot write, covered-log deletion, and deletion
transaction completion. Each pause is exercised through both local and inbound
write paths. A new local edit stays unsaved until its outbox write completes.
Recovery at the snapshot boundary excludes the uncommitted edit; after commitment,
reload recovers the edit and retains its exact pending outbound entry. This model
does not verify native IndexedDB transaction behavior or browser crash durability.

## FE-02: composition and invalid-draft rebasing

Text subscriptions now expose Yjs text deltas. The inspector keeps the draft's
baseline separate from the collaborative value and tracks which current text
positions still belong to that baseline. Peer insertions survive local deletions,
including insertions inside a composition replacement range. Peer deletions move
the local insertion anchor to the next surviving baseline character. Draft state
is reset from the committed collaborative value after successful edits or cancel.

Rebased edits use a command batch whose ranges and final domain value are validated
before one Yjs transaction applies it. No whole-text replacement is used to merge
the draft. The existing field error, cancellation, and caret adjustment paths remain.

Node regressions use two Yjs graph documents and cover peer insertions before,
at, inside, and after a composition range; peer deletions before, inside, and after
it; multiple remote deltas while correcting an over-limit draft; convergence; and
batch validation failure without partial mutation.

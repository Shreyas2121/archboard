## Behavior implemented and proof boundary

The inspector has a named Steps tab with ordered step titles, new-step capture, collaborative
title/notes fields, independent rectangle/highlight recapture, deletion, drag reorder and
named Earlier/Later keyboard alternatives. Authoring uses `EditorSession` mutation wrappers
and the P7-02 commands. The existing writer/session gate checks role/archive, cached offline
authority, local writable ownership and storage/recovery status; narrow views stay read-only.
No editable step array or graph copy is added to UI state.

Capture measures the actual canvas container and current React Flow viewport. Screen-size/
pan/zoom convert to a finite bounded world rectangle. Invalid captures show a zoom/pan hint
without silently clipping. Selection captures unique live cards/connections, excluding
boundaries. Highlight replacement works independently of an out-of-range visible rectangle.
New steps use a bounded order after the current last step, with deterministic ties at the
maximum order; explicit reorder normalizes bounded integer positions in one command.

Present is available for loaded steps regardless of authoring permission. Local playback
hides palette/inspector/editor actions, connections/resizers and presence overlays. The
canvas highlights surviving step references through render props, separate from editor
selection. Previous/Next, title/count, plain-text notes and Exit are named. Left/Right/Escape
respect existing native text, composition, handled-event and modal ownership policy.
Playback fits measured canvas bounds using the installed React Flow geometry helper, updates
on step rectangle or canvas resize, and does not refit for unrelated projection/text edits.
Local panning remains available. Focus enters Exit and returns to the launcher, with toolbar
fallback if the launcher was deleted; if no steps remain and Present is disabled, focus returns
to the canvas. Animation frames, resize observers and key listeners
clean up; session changes clear local playback. No lease or shared viewport writes occur.

Empty/deleted active steps show a truthful unavailable/empty state and an explicit remaining
step choice, with no silent replacement. Cached offline and demo playback share this local
flow; actual browser/offline persistence is deferred, not proved by the build or Node tests.

## Contracts used

P7-02 step commands, append-only tombstones, `(order,id)` projection, atomic rectangles/
references, shared text/geometry/reference/50-step limits and undo origins. ProductTextField

and text history. Y.Doc/outbox remain graph/durability owners; playback IDs/preferences are
local React state. React Flow owns rendering and viewport. No second lease, graph or router.

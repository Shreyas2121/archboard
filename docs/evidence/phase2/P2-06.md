## Behavior proved

- `/demo` owns one lock-aware editor session that opens a fresh Y.Doc, hydrates and validates the
  exact local namespace through sync-client, attaches one local undo manager only while writable,
  exposes an immutable combined status/projection revision through `useSyncExternalStore`, and
  closes subscriptions, undo state, persistence, the document, BroadcastChannel, and Web Lock on
  route cleanup. React Strict Mode's development cleanup opens a fresh replacement session.
- The projection adapter preserves graph IDs, positions, sizes, endpoint IDs, fixed handles, edge
  direction/style, and absolute boundary rectangles. Its per-ID structural cache returns the same
  React Flow object for unchanged graph content; selection creates derived render objects only for
  affected elements and never enters the graph projection.
- React Flow renders nodes and edges from the external projection. Boundaries render through a
  separate transformed viewport portal at background z-order and are never React Flow parent
  nodes. Loading retains the stable shell until hydration supplies a validated projection.
- Space/primary drag and middle-button drag support panning; Ctrl+wheel and trackpad pinch support
  zoom. Named controls provide zoom in/out, fit including nodes and boundaries, reset to the
  default viewport, minimap visibility, and grid preference. These operations do not dispatch a
  document command or write IndexedDB.
- Node and edge clicks update only ephemeral selection references, including Shift-toggle intent.
  Position, connection, deletion, and reconnect callbacks remain unavailable until their owning
  tasks. Read-only and storage-error projections remain inspectable.
- A second desktop tab renders the committed cache read-only, offers Retry, then rehydrates and
  becomes writable after the first tab releases ownership. A narrow viewport opens the cache
  without claiming the writer lock.

## Contracts used

- `GraphProjection`, `GraphNode`, `GraphEdge`, `Boundary`, `HANDLES`, edge directions/styles, and
  `GRAPH_SCHEMA_VERSION` come from `@archboard/contracts`; the frontend defines no graph DTO or
  alternate tombstone policy.
- `BrowserWriterSession`, `LOCAL_DEMO_USER_KEY`, persistence phases, and writer phases come from
  `@archboard/sync-client`. The stable demo UUID plus deployment origin, reserved user key, and
  schema version form the namespace.
- `createLocalUndoManager` comes from `@archboard/document-model`. Durable mutation still requires
  the writer session's guarded document-model command path; P2-06 adds no Y.Map writes.
- Named canvas constants own the 16-unit grid, zoom range/step, fit padding, and default viewport.
  React Flow viewport, measurements, and selection remain outside Y.Doc and IndexedDB.

## Browser evidence

Temporary Playwright observers drove installed Google Chrome against a served production build and
were removed with their isolated browser profile after the run. No browser console error or failed
page script occurred.

- A fresh namespace progressed from the stable loading shell to `Saved on this device`, rendered an
  empty React Flow surface, enabled viewport controls, and retained zero `localUpdates` and zero
  `outbox` records across zoom-in, fit, and reset.
- A second same-origin page showed `Read-only · open in another tab` and Retry. Closing the writer
  caused the second page to rehydrate and report `Saved on this device`; navigating away left zero
  held `archboard:writer:` locks.
- A temporary all-kinds cache contained the deterministic fixture only for observation. The
  production build rendered the exact four node IDs, two edge IDs, and one boundary ID. Node sizes
  were 240 × 140 and 260 × 160 as specified, each node exposed four target plus four source handles,

  included. Node click updated the inspector to `1 selected`; the minimap appeared when enabled.
  Reload reproduced the same IDs, geometry, handles, edges, and boundary from committed IndexedDB.

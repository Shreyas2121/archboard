## Behavior proved

- Every card exposes separate incoming and outgoing `top`, `right`, `bottom`, and `left` React Flow
  handles. The card surface no longer clips the hit area, handles sit above card content, and selected
  edge reconnect anchors are raised above nodes.
- Pointer and keyboard creation build a complete contract-validated edge with a fresh
  `crypto.randomUUID()` ID, forward direction, solid style, and empty label and protocol.
- The canvas renders a forward end arrow, an additional start arrow for bidirectional edges,
  solid/dashed styles, and inert text labels composed from label and protocol.
- The edge inspector edits label and protocol through the incremental Y.Text command and edits
  direction and style through the atomic edge command. Endpoint IDs and handle IDs are displayed as
  immutable values.
- Reconnection creates a complete replacement with a fresh ID and calls the single structural
  `replaceEdge` command, which tombstones the original in the same transaction. It never mutates an
  existing edge's endpoint fields.
- Parallel edges remain valid. UI factories and document-model commands reject self-loops, malformed
  handles, and missing or tombstoned endpoint nodes before mutation, so invalid attempts cannot leave
  a partial edge.
- The alternate connection dialog supports source card/handle selection, target card/handle
  selection, review, back, create, and cancel without pointer input. Self-loop feedback uses an
  accessible alert; canvas outcomes use a status region.
- Projection remains the authority for visibility. Existing projection validation omits edges whose
  endpoints are absent or tombstoned; the canvas adds no view-only endpoint workaround.

## Contracts and ownership

- Edge defaults, handles, directions, styles, field limits, complete edge validation, and UUID
  validation come from `@archboard/contracts`.
- `EditorSession` exposes guarded create, edit, and replace connection methods. UI components receive
  no Y.Doc, Y.Map, or writable Y.Text, and all writes pass through
  `BrowserWriterSession.executeMutation` and document-model commands.
- The shared atomic select field was extracted from the card inspector so edge and card fields retain
  the same labeled Radix Select behavior.

## Accessibility evidence

- The pointer handles retain React Flow's connection indicators, fixed hit targets, and
  visible card-edge placement. The complete dialog flow uses named buttons, labeled selects, a title,
  a description, a review step, and keyboard-operable cancel/back/create actions.
- Edge groups expose source and target handles, endpoint IDs, direction, style, and safe label text in

## Behavior proved

- The web workspace resolves exact compatible React Flow, TanStack Router, Zustand, Tailwind,
  Lucide, shadcn/ui, and Shiki versions from the committed pnpm catalog and lockfile.
- shadcn CLI 4.21.0 initialized `apps/web` with the Radix Nova preset. The source-owned foundational
  set is button, dialog, tooltip, input, label, and collapsible. The generated button source was
  reviewed and unused secondary/link and extra-size variants were removed.
- The reviewed primitive sources retain accessible Radix semantics and local design-token styling;
  rendered behavior tests are intentionally deferred to the feature commits that consume them.
- Tailwind 4 scans local TS/TSX source and exposes local light/dark CSS-variable tokens. Geist font
  files, shadcn styles, and all application assets are bundled locally.
- The web workspace has no automated frontend test dependency, script, configuration, or test file,
  per the user's updated project policy. Shared-package and sync-client tests remain outside the web
  application.
- Package checks reject React, React Flow, and Zustand imports from shared domain packages and React
  imports from sync-client. Four in-memory negative fixtures prove direct and subpath rejection.

## Contracts used

- `packages/contracts` and `packages/document-model` remain independent of React, React Flow,
  Zustand, Nest, and browser persistence.
- `packages/sync-client` remains independent of React.
- All new direct versions are exact catalog values; `catalog:` manifest references do not float.
- shadcn primitives are checked-in source. `components.json` is development metadata; the browser
  has no registry dependency or hosted stylesheet.
- Phase 2 product composition, graph state, routes, persistence, and transport remain absent.

zero bytes to the current production chunks. The final build contains no `shiki`, CDN, unpkg, or
jsDelivr reference; P2-07 will remeasure the granular language imports it actually uses.

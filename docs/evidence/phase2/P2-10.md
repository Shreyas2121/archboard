## Behavior proved

- Duplicate and paste build a strict version-1 Archboard selection payload containing only selected
  cards, explicitly selected boundaries, and edges whose endpoints are both selected. Presentation
  steps, permissions, tombstones, and external connections have no clipboard representation.
- Paste validates the exact format and schema version, creates fresh IDs, remaps internal edge
  endpoints, validates the complete batch, and applies a successive 32-world-unit offset before one
  structural transaction. Invalid text is rejected and points users to the explicit Paste as note
  action.
- The browser adapter reports system clipboard denial and retains only the latest session-local copy
  until reload. It never reports an OS copy after a denied write.
- Delete captures live selected objects and internal edges before one atomic tombstone transaction.
  More than 10 selected objects opens a confirmation dialog; cancellation does not mutate selection,
  history, or the document.
- Only the latest deletion capture remains in session memory. Restore delegates to
  `restoreDeletedObjects`, creates fresh IDs, remaps internal edges, omits external edges, retains old
  tombstones, and clears recovery state after success.
- Local Undo/Redo tracks eligible `LOCAL_EDIT` transactions. Text blur and completed geometry
  gestures stop capture; structural create/delete/duplicate/paste/restore transactions remain
  excluded. An undo with no visible projection change reports that its target was deleted.
- UndoManager-origin updates are now classified as persistable local updates. This preserves the
  resulting graph across reload without persisting the Undo/Redo stacks themselves or introducing a
  Yjs clock gap before later commands.
- Global shortcuts cover clear selection, delete, duplicate, copy, paste, undo, redo, fit, zoom, and
  help with platform-aware labels. Editable inputs suppress canvas routing, preserving native text
  copy, paste, and undo.
- Frontend constants, schemas, shared types, browser adapters, command hooks, and React composition
  live in separate modules. `apps/web/AGENTS.md` records this convention for later work.

## Package assertions

- Existing document-model A13 coverage applies a remote-origin update and then undoes a local edit;
  the remote contribution remains. Capture timeout zero and explicit `stopLocalUndoCapture` calls
  keep separate fields and completed gestures in separate history items.
- Existing document-model A14 coverage deletes selected cards and their internal edge, leaves an
  external edge untombstoned, restores fresh IDs with remapped endpoints, and verifies the original
  tombstones remain.
- A new real-browser sync-client regression performs edit, Undo, and structural delete in sequence,
  waits for IndexedDB, reopens the document, and proves the final empty projection survives. This
  prevents omission of UndoManager-origin updates from creating a causal clock gap.

## Browser evidence

A temporary Playwright observer drove installed Google Chrome through the real editor, clipboard,
Web Lock, Yjs commands, and IndexedDB persistence. The observer and its local servers were removed
after the passing run.

- Created a component and duplicated it. Two consecutive system-clipboard pastes placed the selected
  card at `(368, 448)` and `(400, 480)` after the duplicate at `(336, 416)`, proving successive
  32-world-unit offsets.
- Revoked clipboard permissions and pasted again. The command used the session-local payload and the
  live region reported `Clipboard access was denied; pasted the session-local selection.`
- Deleted the pasted card, restored it, and observed a different ID. The recovery control disabled
  after successful restore.
- Edited a title twice while its input retained focus and pressed Ctrl+Z. Native text undo restored
  the first value, showing that the canvas shortcut handler did not intercept editable controls.
- Used the toolbar Undo for the committed local field edit, then deleted the restored card and waited
  for IndexedDB to report saved.
- Reloaded with four durable cards still present. Undo and Restore deleted were both disabled after
  reload, proving that history and deletion capture remained session-local without changing the
  graph.
- No browser console errors occurred during the scenario.

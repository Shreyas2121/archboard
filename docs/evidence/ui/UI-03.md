Authentication callbacks, pending/error presentation, return paths, and local-demo navigation retain their existing behavior.
- `apps/web/src/app/components/architecture-illustration.tsx`: static DOM/Lucide artwork showing Client → API → Database, an application boundary, and an annotation. It uses semantic surfaces/connector colors, adapts to small widths, and is hidden from assistive technology as accompanying decorative product artwork. It adds no live editor or fake controls.
- `apps/web/src/app/routes/boards-entry-route.tsx`: home/board headers share width, brand typography, spacing, and wrapping geometry. Both online and offline headers retain the UI-02 theme selector, local demo, and sign-out; online account identity remains available. Offline-account and expired-session recovery use the shared page-state composition.
- `apps/web/src/app/components/page-state.tsx`, `apps/web/src/app/routes/route-error.tsx`, `apps/web/src/app/routes/not-found-route.tsx`, and `apps/web/src/features/auth/session-state.tsx`: consistent title, explanation, optional icon, 44px primary recovery action, and quiet secondary navigation. Existing retry, loading, redirect, and session distinctions remain. Theme access is also available on these recovery screens; live regions contain messages rather than interactive controls.
- `apps/web/src/features/boards/board-entry.tsx`: shared presentational frame with 16px padding, 8px radius, neutral border, no default shadow, diagram icon, two-line description, quiet role, and aligned metadata. Titles are real TanStack links when navigation is available; the entire article is not interactive and menus sit outside links. Full title text stays in the link and title attribute.
- `apps/web/src/features/boards/board-dashboard.tsx`: retains search debounce/cancellation, active/archive filter, responsive grid, infinite pagination, first-use/no-results/archive-empty/fetch-error/pagination-error distinctions, and dialog mutation behavior. Repeated Open/Edit/Archive/Duplicate button rows are replaced with linked titles and an always-visible action trigger. New-board primary action is 44px.
- `apps/web/src/features/boards/board-actions-menu.tsx`: Radix menu preserves action availability: active owner/editor can edit, owners can archive or restore according to state, and all roles can duplicate as before. Archive has a separator, explicit wording, and destructive styling; it still opens the existing confirmation. Offline actions remain disabled, with a visible reconnect explanation. Menus hand the persistent trigger to the dialog's return-focus handler and prevent menu dismissal from stealing the opening dialog's focus.
- `apps/web/src/features/boards/cached-board-dashboard.tsx`: uses the same board frame and menu. Titles link only when `locallyAvailable` is true. Partial-list/selected-account/session uncertainty, raw board IDs, cache timestamps, local commit timestamps, stale-detail warning, missing-document recovery guidance, and the storage-is-not-a-backup warning remain visible. Creation and management stay unavailable offline. Active-filter empty wording distinguishes an empty cache from a cache containing only archived entries.
- `apps/web/src/features/boards/board-list-skeleton.tsx`: shared responsive skeleton grid matches the entry frame for online and local-cache loading, respecting reduced motion.
- `apps/web/src/features/boards/board-dialog.tsx`: 512px text forms/448px confirmations, 8px label gaps, 16px related-field gaps, 24px section gaps, and form error description association. Existing submission, validation, idempotency, conflict handling, confirmation, busy behavior, and return-focus semantics remain.
- `apps/web/src/components/ui/dropdown-menu.tsx`: generated with `pnpm.cmd dlx shadcn@4.21.0 add dropdown-menu --cwd apps/web --yes`. The initial sandboxed CLI attempt failed with EPERM accessing the pnpm user directory; the approved retry succeeded. The generated source uses the existing local `cn` helper, semantic border/popover/status tokens, keyboard focus rings, 150ms transitions, and reduced-motion handling. The generated optional checkbox prop was adjusted to omit undefined values for this project's exact optional property types. No existing primitive, configuration, dependency catalog, manifest, or lockfile was overwritten or upgraded.
- `apps/web/public/favicon.svg`: retains the modular mark, matching foundation light/dark colors and browser-chrome system preference. `BrandMark` already uses the foundation semantic tokens and requires no source change. The standalone SVG embeds its paired values because it cannot inherit the application's CSS variables; product JSX uses semantic tokens.

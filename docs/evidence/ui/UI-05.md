## Implemented

- `apps/web/src/app/editor/editor-shell.tsx`: applies `surface-canvas` once to the actual measured canvas region below notices, including loading/recovery states. The outer main region no longer applies the same surface. `graph-canvas.tsx` removes its translucent muted fill and explicitly uses React Flow's transparent background hook. Grid spacing, viewport measurement, creation/fit/zoom formulas, and pan/zoom handlers remain unchanged.
- `cards/card-frame.tsx` and `card-colors.ts`: common 1px neutral frame, 8px radius, 12px padding, dedicated card surface, subtle shadow, and an explicit `auto minmax(0,1fr)` header/body grid. Seven statically mapped saved colors remain visible in a restrained top rule. Solid local selection uses the product ring with canvas-colored separation and does not replace saved identity. Full titles remain available as text/title attributes.
- `cards/component-card.tsx` and `card-layout.ts`: category icon and title form a compact header; description sits below; technology stays as 12px metadata. The existing external link retains its 28px area, safe target/rel, accessible name, pointer propagation policy, and `nodrag`. Descriptions use one line below 114px saved height and at most two lines above it, reserving space for the tallest header and metadata without reducing text size. The existing default 240x140 and legal minimum 160x100 dimensions are unchanged.
- `cards/code-card.tsx` and `highlighted-code.tsx`: bounded scrollable code body uses the paired code surface, 12px/18px monospace text, and matching blank-line height. Horizontal scrolling, keyboard focus, `nodrag`/`nowheel`, theme-dependent Shiki loading, cancellation/fallback, and safe React text rendering remain. Inner vertical padding is 4px to leave room for a scrollbar at minimum height. No code is evaluated or rendered as raw HTML.
- `cards/schema-card.tsx`: compact header and a separate bounded field-surface region, 12px/18px monospace text, preserved whitespace wrapping/scrolling and keyboard focus. The body remains plain text; no schema parser or table behavior was introduced.
- `cards/note-card.tsx`: prose-first 14px/20px body, preserved whitespace and scrolling, long-word wrapping, named visible keyboard focus, and a lighter frame without shadow. The saved-color rule remains; no forced yellow tint is applied.
- `cards/card-handles.tsx`: always-visible neutral handles become primary on hover, focus, selection, or connection. Source/target IDs, eight-handle count, positions/offsets, 10px hit regions, and borders remain. `card-node.tsx` is unchanged: resize limits, callbacks, read-only visibility, and resizer affordances remain. The existing inspector keyboard connection alternative is unchanged.
- `boundaries/boundary-node.tsx`: 1px dashed outline, 5% saved-color fill, 8px radius, and a panel-surface sentence-case title tab bounded to the boundary width. Full title text remains available. The boundary drag-handle class, pointer-event policy, z-index, saved rectangles, 32px minimum, maximum, and selected resizer callbacks remain intact; the fill stays translucent around contained cards.
- `canvas/graph-canvas.tsx`, `projection-adapter.ts`, and `canvas-config.ts`: installed React Flow CSS hooks supply neutral 1.5px edges, primary selected/focused paths and connection previews, and a paired marquee. Label props supply 12px text, canvas-aware backing, and named padding. Arrow markers use the same semantic stroke color, with both markers following primary on local selection. Smoothstep routing, dashed styling, bidirectional start/end markers, label/protocol composition, endpoint IDs, caching, reconnect behavior, and geometry are preserved.
- Minimap uses the panel surface, neutral node color, paired canvas mask with visible viewport outline, rounded frame, and subtle shadow. Existing pan/zoom and the library attribution remain; attribution gets the paired surface and readable muted text.
- `collaboration/presence-colors.ts` and `presence-overlay.tsx`: assigned colors map to the seven dedicated paired presence tokens. Peer selections are dashed with name tabs; transient drag outlines are dotted with a named moving label, distinguishing both from solid local selection. Cursor labels and peer chips use readable floating surfaces with bounded long names. User/connection identity, counts, subscriptions, runtime world coordinates, viewport transforms, pointer-event policy, and z-index 1001 above selected nodes remain.
- No dependencies, schemas, durable dimensions, document commands, permissions, persistence, Y.Doc ownership, or text-history contracts were changed. Styling uses Tailwind utilities. The narrowly scoped library node-focus/attribution selectors target React Flow-owned DOM; required edge/marker/label props and runtime presence coordinates retain documented third-party/dynamic-value exceptions. No component CSS was added.

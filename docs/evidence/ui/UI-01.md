## Implemented

- `apps/web/src/styles.css`: paired warm light and blue-charcoal dark tokens for page, canvas, panel, node, popover, and field surfaces; explicit primary hover, connector, overlay, status surfaces, presence identities, and code surfaces. Existing semantic aliases remain available; sidebar tokens use the same roles. Existing graph and chart palettes are retained. Presence/code/connector tokens are ready for their UI-05 consumers; defining tokens does not complete those integrations.
- Radius roles are explicit: 6px controls, 8px cards/popovers, 12px dialogs. The base body scale is 14/20px, retaining Geist. Product compositions with explicit typography/radius overrides remain for later work packages.
- `apps/web/src/components/ui/button.tsx`: 36px standard, 32px small/compact and icon controls, additive 44px large/touch options, existing 28px icon-sm retained. Existing size and variant names remain supported. Targeted 150ms color transitions, reduced-motion handling, explicit primary hover, paired destructive surface, no press translation, and a border plus accent fill for pressed states.
- `input.tsx`, `textarea.tsx`, `select.tsx`: field surfaces, essential control borders, shared solid 2px focus ring with offset. Inputs/selects align at 36px; select small is 32px. Input/textarea/select retain 16px mobile text with 14px desktop text. Textarea resizing and scrolling remain available. Select retains its selected checkmark and adds an inset keyboard focus ring distinct from selection.
- `label.tsx`: readable 14/20px label scale with existing Radix association behavior.
- `dialog.tsx`: paired backdrop, 12px radius, border and shadow, 512px default desktop maximum width, 16px mobile/24px desktop padding, viewport-bounded scrolling, 20/28px heading, and a plain footer. Existing focus trap, Escape policy, close API, and caller handlers remain intact.
- `tooltip.tsx`: 300ms default delay, 12/16px text, 6px radius, 150ms opacity animation. Dialog, select, and tooltip animations respect reduced motion; scale animations were removed.
- Audited `collapsible.tsx` and `apps/web/src/app/components/icon-button.tsx`: no changes needed. IconButton retains its 32px default hit area, tooltip, accessible label, caller size overrides, and ref forwarding through the existing React 19 props. Collapsible continues to delegate behavior to Radix; trigger compositions belong to the screen work packages.

DropdownMenu is not required by a UI-01 consumer. Add it through shadcn CLI `4.21.0` when UI-03 introduces board action menus; do not hand-build it or overwrite customized primitives.

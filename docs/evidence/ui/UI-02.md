# UI-02 Theme access

Date: 2026-09-30. Implementation and focused non-browser verification complete. Visual acceptance remains pending.

## Implemented

- `apps/web/src/app/components/theme-control.tsx`: one shared Radix Select composition with explicit Light, Dark, and System options. It uses `useTheme().setPreference`, provides an accessible name including the current choice, and retains a compact 32px icon presentation for the editor. Trigger and menu keyboard events stop propagation so theme interaction cannot invoke editor shortcuts; Radix owns selection, dismissal, and focus behavior.
- `apps/web/src/app/routes/home-route.tsx`: selector added beside the existing demo action. Header actions can wrap at small widths.
- `apps/web/src/app/routes/boards-entry-route.tsx`: selector added to both online and cached/offline board headers, retaining account identity, local demo access, and sign-out behavior.
- `apps/web/src/app/editor/editor-toolbar.tsx`: the cycling theme button is replaced by the same selector in its compact presentation.
- `apps/web/src/platform/theme/theme-preferences.ts`: shared preference types, validation, display options, existing `archboard.theme` storage key, and existing OS media query.
- `apps/web/src/platform/theme/theme-preference-storage.ts`: guarded storage accessor, read, and write operations with an in-memory session choice. Missing/invalid/unavailable storage defaults to System. Failed persistence never discards a selection or throws into startup/provider callbacks. Initialization and provider mounting read the same session choice.
- `apps/web/src/app/theme/theme-provider.tsx`: uses the guarded storage adapter and immediately synchronizes resolved theme, root dark class, theme dataset, and `color-scheme` when a choice changes. Existing pre-React initialization in `main.tsx`, System media listener/cleanup, context provider, and cycle API are retained. Preference constants/types are re-exported for compatibility.
- `apps/web/src/platform/theme/theme-preference-storage.test.ts` and `apps/web/src/app/theme/theme-provider.test.ts`: focused Node tests for persisted choices, invalid values, storage accessor/read/write failures, session retention, and initialization with explicit/System preferences using mocked browser globals. These tests do not render React or launch a browser.

No dependencies, routing, authentication, permissions, document behavior, or alternate theme state were added. Theme control insertion is complete for the UI-03/UI-04 primary headers; their broader redesign remains with those work packages.

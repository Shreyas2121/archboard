## Behavior proved

`ValidationWorkerPool` copies accepted-state and update bytes into a real Node.js worker thread. The
worker reconstructs isolated accepted and candidate Y.Docs, checks C10 causal completeness, and runs
complete document-model validation before returning a full candidate state. The caller's accepted
bytes are never transferred, detached, or mutated.

The pool consumes the C02 operational defaults: a 2,000 ms deadline, at most two active workers,
and at most 32 queued jobs. Each job owns one worker. Completion, rejection, crash, and timeout all
terminate that worker and drain no more than the configured concurrency. A full queue rejects
immediately with retryable `SERVER_BUSY` / `overloaded`; timeout and worker failure use the same
stable wire error with distinct internal failure kinds. Malformed, limit, and causal failures retain
their stable non-retryable document error codes.

Tests use deterministic directives for a hanging worker and a crashing worker. They also exercise
real malformed bytes, one-over-limit state, a causally incomplete update, and the typical and limit
graph fixtures. Every rejection path asserts that accepted state remains byte-for-byte unchanged;
the timeout test additionally observes zero active workers after rejection.

## Failure injection

`hang` affects exactly the next submitted job and keeps its worker alive until the pool's deadline
terminates it. `crash` throws inside exactly the next worker. These controls never bypass scheduling,
worker startup, byte cloning, or pool cleanup. A one-worker/one-queued-job test fills both bounds and
proves the third job receives explicit overload while the queued job later completes normally.

## Known gaps

This is a bounded validation prototype, not a production room integration. It does not select an
autoscaling policy, reuse workers, distribute queues, persist accepted state, or define production
capacity. C11 remains the durable acceptance proof; a later production collaboration path must call
this boundary before persistence and promote only its successful candidate result.

# C04 — Add deterministic Phase 1 scenarios

Parent: `c62a87fc7ec78f387c2bd541bb55fca3675adfd3`<br>
Environment: Windows, Node.js 22.23.2, pnpm 11.24.0

## Behavior proved

`@archboard/fixtures` now provides deterministic minimal, all-entity, typical-size, exact-limit,
malformed, and one-over-limit fixtures. The minimal graph contains two component nodes and one
connection. The all-entity graph covers all four node kinds, all four handles, both edge styles and
directions, a boundary, and two presentation steps. The typical graph uses the named 200-node and
400-edge measurement shape; the limit graph reaches every live-entity cap and places representative
content and geometry exactly at every shared maximum or minimum.

The package exports fixed valid application UUIDs, four deterministic delivery seeds, nine
framework-neutral concurrency scenarios, eight physical-schema malformation descriptors, and
structure/delete-set causal-gap descriptors. It imports no Yjs, React, React Flow, or NestJS code.

## Contracts used

- Every valid logical graph is parsed through `graphProjectionSchema`.
- Forty-six invalid candidates cover unknown fields, invalid IDs, mismatched node content, malformed
  nested values, unsupported enums and URLs, duplicate IDs, non-finite values, and one-over-limit
  field, geometry, entity, payload, selection, and drag-preview values.
- Fixture builders take named `nodeCount`, `edgeCount`, `boundaryCount`, and `stepCount` parameters
  and reject negative, unsafe, or impossible count combinations before allocation.
- Raw WebSocket frame size is represented by an explicit maximum/one-over descriptor because frame
  enforcement occurs before parsed message schemas.
- Concurrency operations are semantic inputs only: rename, move, resize, incremental text insert,
  tombstone, create node/edge, reorder step, and local undo.

## Failure injection

Invalid logical candidates are generated lazily and parsed through the schema assigned by each
fixture. Tests require both rejection and an issue at the declared path, preventing a fixture from
passing for an unrelated reason. Oversized Yjs strings encode deterministic zero bytes; the raw
WebSocket frame case stores lengths without allocating a 16 MiB frame.

Physical failure descriptors cover wrong root type, wrong nested type, invalid stored enum and ID,
immutable-field mutation, physical entity removal, false tombstone values, and tombstone removal.
They are materialized against Yjs by C05/C10 rather than fabricating implementation-specific bytes
in C04.

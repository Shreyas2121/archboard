# C07 — Prove convergence and delete-wins semantics

Commit: recorded in Git history by this evidence file's commit
Parent: 8073d80f4de311294b7f726856f0a6cac8e3c5b4
Environment: Windows, Node.js v22.23.2, pnpm 11.24.0, Yjs 13.6.32

## Behavior proved

Independent `Y.Doc` replicas initialized from one encoded baseline converge after receiving the complete accepted update set. Deterministic tests prove A02 concurrent rename/move, A03 same-position collaborative text insertion without whole-field loss, A04 concurrent atomic moves without asserting a wall-clock winner, and A05 delete-versus-edit plus delete-versus-incident-edge behavior.

Additional tests prove concurrent move/resize survival, unique concurrent creation, deterministic `(order, id)` presentation-step ordering, and A13 local undo after a remote edit. The undo removes the local title change while retaining the independently produced remote position.

Randomized coverage runs all nine concurrency scenarios twelve times for each of four fixed seeds: 432 seeded scenario runs total. Each run delivers two copies of every source update in independently shuffled orders to three fresh replicas, then compares their complete observable projections. The randomized test has a named 10,000 ms execution budget and a 15,000 ms hard timeout.

## Contracts used

The suite consumes the C04 fixed concurrency scenarios and seeds, the C06 public command/origin/undo behavior, and the C05 deterministic projection. It uses the shared graph types, handles, edge direction, and edge style constants. No test reaches into Yjs causal internals or chooses a concurrent atomic winner based on wall-clock time.

## Failure injection

The delivery harness deterministically reorders updates, duplicates every update, and exercises updates that arrive before their causal predecessor in the local-undo scenario. Delete races inject an edit and a newly created incident edge from an independent replica after the other replica appends the node tombstone. Every replica receives the complete update set before comparison.

## Measurements

The document-model suite completed in 2.81 seconds during the targeted run and 2.93 seconds during the full workspace run. The randomized section remained below its named 10,000 ms CI budget. These are test-bound observations, not product performance claims.

## Known gaps

Causal-gap rejection is deliberately not inferred from Yjs buffering in these tests; the isolated compatibility boundary and its incomplete-update fixtures belong to C10. Network transport and durable persistence remain out of scope.

# C03 — Define shared contracts, limits, and errors

Parent: `481c90369e8776e63bcd425749427f100b14af6d`<br>
Environment: Windows, Node.js 22.23.2, pnpm 11.24.0

## Behavior proved

`@archboard/contracts` now provides framework-independent strict Zod schemas and inferred types for
the complete Phase 1 logical graph projection. The node schema is discriminated by `kind`, and each
kind accepts only its matching content shape. Every nested object rejects unknown fields. Graph
validation rejects malformed UUIDs, non-finite or out-of-range geometry, unsupported enums and URL
schemes, duplicate entity IDs, oversized text and entity collections, and excessive combined step
references.

The package also defines the strict Phase 1 client/server WebSocket unions, stable event names and
error codes, canonical padded-base64 validation with decoded-byte limits, bounded presence shapes,
and canonical non-negative PostgreSQL `bigint` sequence strings. Sequences remain strings throughout
parsing and cannot overflow the PostgreSQL type.

## Contracts used

- Graph schema version `1` and protocol version `1`.
- Exact `Point`, `Rect`, component/code/schema/note node, edge, boundary, presentation-step, and
  `GraphProjection` shapes from `phase1.md`.
- All core field, geometry, entity-count, encoded-state, client-update, WebSocket-frame, selection,
  and drag-preview limits have one named source under `src/limits`.
- Client events: `hello`, `update`, and `presence`.
- Server events: `ready`, `ack`, `update`, `presence`, `error`, `access.changed`, and `invalidate`.
- Canonical collaboration errors include the required permanent failures and
  `PERSISTENCE_FAILED` for retryable commit failure.
- Presence drag previews use one strict `{ positions: [{ id, position }] }` object with unique UUIDs
  and at most 100 positions. Better Auth user IDs remain nonempty strings rather than being assumed
  to be UUIDs.

## Failure injection

Tests submit unknown envelope and nested fields, mismatched node discriminators, invalid UUIDs,
NaN and out-of-range geometry, unsupported enums and URL protocols, duplicate IDs, every bounded
text/entity class over its limit, excessive references and presence selections, malformed and
non-canonical base64, oversized decoded updates, invalid decimal sequences, and PostgreSQL `bigint`
overflow. Every candidate is rejected by the shared boundary.

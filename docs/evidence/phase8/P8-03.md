## Behavior implemented and supporting proof

Properties now has **Browse objects**, a labeled filter, full current-projection
card/boundary/connection discovery, single/group selection, **Go to selected
properties**, clear and pagination controls. Select only focuses the named property
region. Selection uses the existing ephemeral store; editing still uses the session
and document-model commands. The focusable canvas and explicit object controls
replace React Flow's separate native keyboard object mutation path.

Narrow **Board panels** reuses Properties/Steps/Discussion in a named Radix modal;
mutation remains disabled, and choosing Present closes the panel. Presentation
controls and toolbar/footer rows accommodate text growth; palette/inspector controls
expose their collapse state. Existing numeric geometry, keyboard connection and
Earlier/Later step ordering were extended, not duplicated. Card/boundary/connection
limits are explained from shared constants without changing admission rules.

Geometry rejects empty/non-finite input before mutation and associates failures
with fields. Connection review catches missing endpoints as well as self-loops;
review/error/Back transitions have explicit focus and failure associations. The
existing create command continues to validate actual graph references and authority.
Step reorder focuses the moved step and reports its new position. Focus recovery
after an unavailable object/control respects another control or external modal;
hidden object browsing falls back to the active panel tab. Object deletion and
large-delete modal closure return to the canvas; panel closure has useful focus.

Board action dialogs return to the Your boards heading if their menu opener disappears.
The shared existing DialogContent retains Radix initial/modal focus behavior and
explicit caller policies, remembers programmatic openers and falls back to the
canvas when an editor opener disappears or is disabled. Existing board/import/
discussion error messages now describe their relevant controls. Text commits keep
focus and IME composition bypasses command keys. Shortcuts ignore form fields,
editable/combobox/menu/listbox/slider ownership and dialogs. Ctrl/Cmd +/- now remains
native browser text zoom; unmodified F/+/- controls the canvas. Keyboard help and
the prepared protocol explain command scope and all alternate paths.

Visible save/permission/offline/pending text remains current. Spoken editor state
settles for 800 ms, deduplicates equal messages, omits per-receipt/count changes and
spaces routine messages by 10 seconds; important noneditable states bypass the
routine interval. Existing semantic local error/presenter notices, theme tokens,
focus styling, reduced-motion dialogs/skeletons and zero-duration presenter fitting
remain. These are source/policy properties, not observed assistive-tool acceptance.

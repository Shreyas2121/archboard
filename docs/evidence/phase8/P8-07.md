## Delivered implementation

Added the pinned multi-stage API/web Dockerfile, single-writer Compose package,
same-origin Caddy routes, generated CSP/referrer/nosniff/HSTS headers, persistent
PostgreSQL volume, private DB network, file secret loader and nonsecret example.
Only Caddy publishes ports. API uses one nonroot Nest process with init, read-only
storage, one bounded tmpfs and 30-second stop grace. There are no automatic
migrations or synchronization, raw access logs, published DB ports or cluster workers.

Runtime admission requires dedicated writer ownership and schema readiness before
HTTP handlers, upgrades and product transactions accept work. Startup/readiness use
read-only migration history and product/auth metadata checks; missing tables/types/
keys, incompatible history, lost DB ownership and stopping return unavailable.
Liveness remains process-only. Dedicated connection error/end fences admitted
commits and terminates immediately. Ownership loss never reopens this process.

SIGTERM/SIGINT stop admission/readiness, close sockets and drain workers, gateway/
upgrade/maintenance work and admitted transactions before room disposal and lock
release. A 20-second collaboration watchdog and 25-second complete-process watchdog
terminate stuck shutdown while ownership is held. Graceful readiness probes preserve
the commit fence for already admitted transactions. Uncommitted work cannot ACK or
broadcast; exact ID/byte retry retains the existing receipt/sequence contract.
Safe runtime state events and shutdown duration supplement existing filtered queue,
validation, commit, ACK, rejection and compaction telemetry.

The [operations runbook](../../phase-8-operations.md) records configuration/secrets,
OAuth callback/HTTPS, routing/privacy, health signals/operator actions, explicit
migrations, upgrade/rollback limits, image verification and exact deferred procedures.
No DNS/OAuth account, monitoring service, remote deployment or paid service was created.

full migration constraint/default/index behavior still needs real integration proof.

owners, new safeguards and exact prepared integrated/manual cases. Production
origins must share one HTTPS origin; Better Auth retains its CSRF/origin/session
model with explicit secure HttpOnly SameSite cookies. Generic protected responses
now get no-store/referrer/nosniff before auth/CORS/parsers, including errors and
unknown protected paths. Bundled HTML uses scoped same-origin CSP; production host
headers and proxy redaction are specified for P8-07, not claimed deployed.

Framework exceptions and provider arguments are withheld. Safe telemetry filters
event/field/value types; scans include source maps and credential/token patterns,
with counts-only public/evidence results and synthetic negative canaries.

Aborted session reads, session-boundary switch approval, asynchronous access grants
and editor-set/account changes during worker preparation fail closed. Node tests
prove retained graph bytes after local denial and no stale grant/drain/close. The
existing complete recovery serialization and explicit destructive preservation
choices remain; no document/outbox/account cache is deleted by this task. Server
roles, archive/lease/session cadence, committed ACKs, receipts, FIFO retry and shared
strict graph/import/export contracts are retained.

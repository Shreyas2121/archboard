- Environment: Windows, Node.js 22.23.2, pnpm 11.24.0, Chrome 153.0.8010.53, Vite 8.3.0, vite-plugin-pwa 1.3.0; no PostgreSQL required for this static-shell task.

## Behavior proved

The production preview installed and activated `/sw.js`. A later controlled navigation loaded `/demo`, `/boards`, and a direct UUID editor URL while Chrome was offline. The latter two loaded the application shell only; account selection and board hydration are P5-02 through P5-04. A fresh browser context opened offline could not load `/boards`. Missing assets, API/auth callback, WebSocket, invite, and non-UUID board paths did not receive the shell offline.

## Contracts used

Workbox precaches only generated local static assets and uses a navigation fallback restricted to `/`, `/demo`, `/boards`, and UUID board routes. It has no runtime caching rule. `/api`, `/ws`, `/auth`, and invite paths are denied. Registration does not force a waiting worker to activate or claim open clients. The service worker does not read or store graph/account data.

## Changed scope

`apps/web` Vite PWA configuration, manual production registration, HTML CSP, production-preview browser harness; exact PWA/minifier catalog pins and lockfile. The `terser` pin is needed by the Workbox build path in this pnpm graph. No API or sync-client code changed.

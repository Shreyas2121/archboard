## Behavior proved

The protected `/boards` route displays the current user and supports sign-out, debounced title search, active and archived lists, cursor-backed load more, and role-aware board cards. It offers blank creation, metadata edits, archive, restore, and committed-state duplication through dialogs. Each create or duplicate intent uses a UUID idempotency key; retries of identical form data reuse it, while changed data gets a new key. A 409 version conflict fetches current board details, invalidates the list, explains the conflict, and disables the stale dialog submission. Query keys separate search and archive results, and in-flight list requests receive abort signals. The route distinguishes initial sign-out from a session that expires while boards are open.

## Contracts used

`boardListResponseSchema`, `boardDetailResponseSchema`, board request schemas, shared board roles, title and description limits, `VERSION_CONFLICT`, and the standard API error envelope. The browser does not access cookies or store board arrays in Zustand. Duplicate copy says it uses the committed server version.
